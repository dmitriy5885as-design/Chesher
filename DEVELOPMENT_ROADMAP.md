# MEME CHESS — Дорожная карта

Текущая версия: **v0.18.3**

## Главный принцип

**Meme Mode не должен изменять правила шахмат и не должен ломать существующие игровые режимы.**

Шахматный движок сообщает игре, что произошло. Meme-система решает, нужно ли на это реагировать.

```
CHESS ENGINE → GAME EVENT → EVENT BUS → MEME MODE → REACTION → Animation / Sound / Video
```

А НЕ:

```
ChessMoveGenerator → if meme... → playGun()
```

## Правила разработки

1. **НЕ переписывать существующий шахматный движок ради Meme Mode.**
2. **НЕ переносить Meme Mode-логику в ChessMoveGenerator, BoardGenerator, GameManager или другие базовые шахматные модули.**
3. **Использовать события/интерфейсы между системами.**
4. **Любое изменение существующей логики должно сохранять поведение Classic, Bots, Fischer-960 и Daily.**
5. **Каждый этап выполнять отдельно. После каждого этапа проверять все режимы.**
6. **Не переходить к следующему этапу, если предыдущий не стабилен.**
